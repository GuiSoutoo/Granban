# Gemini Context for Granban

## Project Overview
Granban é um projeto de um sistema de board Kanban voltado para desenvolvedores de sistema.

## Tech Stack
- Frontend: React (Vite)
- Backend/Service: Firebase
- Styling: CSS (Uma mistura de Bootstrap com estilo feito a mão)

## Coding Conventions
- Usando componentes

## User Preferences
- Language: Portuguese (PT-BR)

## Caminho atual
No momento, estamos fazendo o escopo do projeto, trabalhando no crud dos principais elementos (Tasks, depois Projetos, e só então implementar sistema de login e cadastro)

## Desejos
Deixar o código mais polido e organizado possível, simplificando ao máximo a lógica utilizando das tecnologias fornecidas pelo React

## Alguns diferenciais
No kanban, as tarefas tem informações simples como titulo e data de entrega. No nosso, tem sistema de tag que carrega algumas tags para organizar o quadro de um verdadeiro desenvolvedor, separando por exmeplo entre bugs, melhorias, alterações, funcionalidades, e outros termos. Além de ter sistema de prioridade, e a aba de revisão que quando aperta para ver aquela task com status em revisao, os botoes dos detalhes da task muda para rejeitar ou concluir.
